## Definition of Done documentaire

- [x] Architecture de navigation définie.
- [x] Parcours critiques décrits.
- [x] Écrans du MVP inventoriés.
- [x] Contenu et actions principales spécifiés.
- [x] Composants réutilisables identifiés.
- [x] États d’interface et erreurs documentés.
- [x] Responsive mobile, tablette et desktop défini.
- [x] Exigences d’accessibilité intégrées.
- [x] Scope conforme au PRD et aux ADR.
- [x] Documents versionnés sur une branche dédiée.

## Hors périmètre de cette étape

- Direction artistique haute fidélité.
- Design tokens définitifs.
- Prototype interactif Figma.
- Schéma SQL.
- Contrat OpenAPI.
- Code React ou Next.js.
- Tests automatisés.

Ces éléments seront traités dans les étapes et issues dédiées afin de ne pas mélanger le cadrage fonctionnel et l’implémentation.
