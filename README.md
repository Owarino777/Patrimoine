# Patrimoine — MVP

Assistant patrimonial long terme permettant de centraliser ses comptes, suivre son allocation, simuler des scénarios et documenter ses décisions d’investissement.

## Statut

Phase 0 — cadrage produit et architecture.

## Principes

- Monolithe modulaire
- TypeScript strict
- Domaine indépendant du framework
- PostgreSQL comme source de vérité
- Aucun trading automatique
- Aucune recommandation d’achat/vente automatique
- IA limitée à la synthèse et à l’explication
- Accessibilité, sécurité et traçabilité intégrées dès le départ
